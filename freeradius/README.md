# FreeRADIUS

A minimal [FreeRADIUS](https://freeradius.org/) server for Home Assistant OS.
Use it for WPA-Enterprise Wi-Fi, 802.1X or any other RADIUS client in your
network.

## Features

- Authentication with PEAP-MSCHAPv2 and PAP
- Users, passwords and optional VLAN assignment, all managed in the Home
  Assistant add-on configuration
- Shared secret and allowed client network configurable
- EAP certificates are generated automatically and stored persistently
- Optional debug mode for troubleshooting

See the **Documentation** tab for setup instructions.
